# DAKH

A rough Unity 2D timing-based combat prototype.

## Current Status

Phase 1 completed:
- Player stands at the center.
- Enemies spawn from the left or right.
- Enemies move toward the player.
- Player attacks left with A / Left Arrow.
- Player attacks right with D / Right Arrow.
- Correct direction + correct range destroys enemy.
- Enemy touching player triggers Game Over.

## Technology

- Unity 6.3 LTS
- C#
- 2D Core project

## Controls

| Key | Action |
|---|---|
| A / Left Arrow | Attack Left |
| D / Right Arrow | Attack Right |
